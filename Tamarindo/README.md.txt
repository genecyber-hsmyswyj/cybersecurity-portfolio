# 🎤 Pirulín el Drogadicto 🎶

**Una canción irónica, cómica y totalmente inofensiva escrita en Python por Genesis Ramos.**

> *"Me llaman Pirulín el drogadicto... pero solo tomo juguito de tamarindo."*

Este proyecto contiene una canción impresa desde la consola, dividida en secciones como un verdadero hit musical: coro, versos y puente.

---

## 📝 Descripción

**Pirulín** es un personaje incomprendido. Algunos piensan que está "perdido", pero en realidad solo tiene hábitos extraños, sueña despierto y toma decisiones culinarias cuestionables. El código presenta su historia en formato de canción, con un estilo humorístico y muy peculiar.

---

## 🛠️ ¿Qué contiene?

El archivo `pirulin.py` incluye:

- `coro()` – ¡El gancho pegajoso!
- `verso_1()` – Introducción a la locura de Pirulín.
- `verso_2()` – Rumores del barrio y pagos inusuales.
- `puente()` – Las escenas más surreales de su vida.
- `cantar()` – Función que ejecuta toda la canción.
  
---

## ▶️ Cómo ejecutarlo

1. Asegúrate de tener Python instalado en tu computadora.
2. Descarga o clona este repositorio.
3. Abre una terminal o consola en la carpeta del proyecto.
4. Escribe lo siguiente:

```bash
python pirulin.py
